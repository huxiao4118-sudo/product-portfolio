Olist 系统使用与数据说明

1. 打开方式

双击 START_HERE.html，用 Edge 或 Chrome 打开。原型介绍及演示.html 是同一首页的备用入口。

整个文件夹需保持完整；如果收到的是 ZIP，请先完整解压。网站不需要联网，也不需要安装 Python、Node.js 或 MySQL。

  • offline_site/operations.html：运营总览、订单队列、订单详情及客服记录。
  • offline_site/dashboard.html：履约监控及模型效果分析。
  • presentation/：系统介绍 PPT。
  • demos/：三段高清功能演示 GIF。
  • docs/：项目说明、需求与验收、数据口径和数据库关系。
  • figures/：页面使用的分析图表。
  • database/：完整 MySQL 数据库、建表代码和导入说明。

2. 数据如何使用

页面使用 offline_site/offline-data.js 中随包附带的历史数据。它由原 MySQL 数据库导出，包含 25,540 笔已有预测结果的订单、原有客服事件、州信息，以及已保存的模型测试结果。

浏览器加载后，将订单数据用于日期筛选、地区筛选、订单状态判断、队列排序和图表汇总。所有资源在本地读取，不请求后台 API，不连接数据库，也不重新训练模型。

offline-data.js 必须保留，不能单独删除或随意修改。MySQL 数据库和建表代码保存在 database 文件夹中，用于独立导入和查看结构；模型文件和 Python 源码不参与离线页面运行，未包含在此版本中。

3. 日期、地区与订单状态

  • As of：回放选定历史日期中午 12:00 的订单状态；只显示该时点前审核通过的已评分订单。
  • Customer state：按消费者所在州筛选，不是商家所在州。
  • Pending delivery：统计时点尚未送达的订单。
  • Overdue：尚未送达，且已经超过承诺送达日期。
  • Due within 2 days：尚未逾期，承诺日期在当天至未来两天内。
  • At risk：当前待送达订单中，预测风险达到第 80 百分位，且排除已逾期及两天内到期订单。
  • Awaiting carrier / In transit：截至统计时点是否已经交给承运商。

日期切换改变的是历史履约状态；显示的延迟概率仍是订单审核时的预测，不是该日期重新计算的实时风险。

4. 订单队列与详情

队列依次按已逾期、两天内到期、高风险和其他待送达订单排序。同一类别中，先按逾期天数降序，再按预测风险降序，最后以订单 ID 保证排序稳定。

支持按异常类别、配送阶段筛选，以及按订单 ID 或商家 ID 搜索。点击 View 可查看风险概率、商品金额、地区路线、商家、品类和配送时间线。

Export CSV 导出当前筛选条件下的全部匹配订单，不仅是页面展示的前 25 条。

5. 客服记录如何保存

Case progress 可以选择 Open、Investigating、Contacted、Resolved，并填写跟进备注。每次保存新增一条处理历史，不覆盖旧记录。

新增记录只保存在当前浏览器的本地存储中，不上传，也不修改原始 MySQL 数据。通常刷新后仍可查看；更换浏览器、清除浏览器数据或禁用本地存储后，记录可能不可用。

客服状态显示最新记录，不随历史日期回溯。Resolved 表示处理记录中的状态，不代表订单已实际送达。

6. 模型效果页如何阅读

Model performance 展示固定的历史测试集结果，不随运营页面的日期或地区筛选变化。测试集包含 18,739 笔订单，其中 717 笔实际延迟。

各策略每天选择约 10% 的订单，共选 1,915 笔。风险优先捕获 162 笔实际延迟订单，召回率约 22.6%；随机策略 50 次平均捕获 72.66 笔，因此风险优先的捕获量约为随机的 2.23 倍。

该结果验证的是历史样本上的选单效果，不代表客服介入已经减少真实延迟、节约人力或提高满意度。风险加权金额也不能直接解释为预计损失。

7. 文件保留规则

START_HERE.html、offline_site、demos、figures、presentation、docs 以及 README.html 是相互关联的页面和资源。不要单独移动 HTML、删除 offline-data.js 或删除 plotly.min.js，否则部分页面、图表或链接可能失效。

8. MySQL 数据库文件

完整导入使用 database/Olist_21_tables_mysql.sql.gz（先解压为 SQL）；仅创建空表使用 database/Olist_21_tables_schema.sql。两者不要按顺序重复执行。

查看数据库导入说明。查看离线网站无需导入数据库。
