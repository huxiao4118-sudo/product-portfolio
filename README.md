## 研究与分析

- [智能健康手表市场调查](projects/market-research/report.pdf)：围绕智能健康手表的发展现状与用户需求开展调查分析，提供完整研究报告和答辩材料。
- [AI 岗位薪资预测与影响因素](projects/ai-salary/report.pdf)：使用随机森林、XGBoost 预测 AI 岗位薪资，结合特征分析与文本分析探索影响因素。
- [可转债量化交易策略](projects/convertible-bonds/report.pdf)：比较时序标准化后的双低因子与机器学习多因子策略，分析收益、回撤和风险表现。
- [投资组合优化与 VaR 分析](projects/portfolio-var/report.pdf)：围绕夏普比率最大化构建投资组合，并通过风险价值指标分析组合风险。
- [金融机构信贷与经济波动](projects/credit-research/report.pdf)：使用 SVAR、BVAR 及约束识别方法，研究信贷冲击对宏观经济波动的影响及传导路径。

## 使用说明

直接打开在线首页即可查看原型，无需运行后台或数据库。报告为 PDF，代码与 PPT 可下载。Olist 完整 SQL 已 gzip 压缩，先解压再导入 MySQL。演示备注仅存储在查看者浏览器中。公开报告副本遮盖学号并移除 PDF 元数据，原始资料未改动。

数据来源、方法、引用及团队署名详见各报告；本仓库用于项目展示。
